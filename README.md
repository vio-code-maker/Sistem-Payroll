# Sistem-Payroll
 sistem informasi yang digunakan untuk mengelola dan menghitung gaji karyawan secara otomatis. Sistem ini mencakup pengelolaan data karyawan, gaji pokok, tunjangan, potongan, absensi, serta pembuatan slip gaji. Sistem ini bertujuan untuk mempermudah proses penggajian, mengurangi kesalahan perhitungan, dan meningkatkan efisiensi admin perusahaan
